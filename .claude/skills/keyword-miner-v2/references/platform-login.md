# 平台登录指南

## dash.3ue.co 登录流程

### 1. 打开登录页
```
navigate_page → https://dash.3ue.co
```

### 2. 填写登录表单
- 找到用户名输入框，填入：`niko`
- 找到密码输入框，填入：`111111`
- 点击登录按钮

### 3. 验证登录成功
等待页面出现 "SEO Tools" 区块

### 4. 选择工具
在 SEO Tools 区块中：
- Similarweb 卡片 → 点击"打开"
- SEMrush 卡片 → 点击"打开"

## 注意事项

- 如果登录失败，截图页面让用户确认
- 工具可能在新标签页打开，注意切换
- 会话可能超时，需要重新登录
