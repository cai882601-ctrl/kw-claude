# SEMrush 关键词分析指南

## 进入 SEMrush

从 dash.3ue.co 的 SEO Tools 区块点击 SEMrush "打开"按钮。

## 关键词查询

### 方式 1: 单个关键词查询

1. 找到 Keyword Overview 或搜索框
2. 输入关键词（如 `online resume builder`）
3. 选择目标市场（通常选 US 或 Global）
4. 提交查询

### 方式 2: 批量关键词查询（如果支持）

1. 找到 Keyword Magic Tool 或 Bulk Analysis
2. 批量输入多个关键词
3. 导出结果

## 需要提取的数据

| 数据点 | 含义 | 筛选用途 |
|--------|------|----------|
| Volume | 月搜索量 | 判断市场规模 |
| KD | 关键词难度 (0-100) | **核心筛选指标** |
| CPC | 单次点击成本 | 判断商业价值 |
| Competition | 竞争密度 | 辅助参考 |
| Trend | 搜索趋势 | 判断增长/衰退 |

## KD 解读

```
KD 0-20:   Very Easy   → 新站 3-6 个月可排名
KD 21-40:  Easy        → 需要一定内容和外链
KD 41-60:  Medium      → 需要大量内容和权威外链
KD 61-80:  Hard        → 需要强大域名权重
KD 81-100: Very Hard   → 只有顶级网站能竞争
```

## 常见问题

- 免费版可能有查询次数限制
- 部分关键词可能无数据，标记为 "N/A"
- KD 和 Volume 可能在不同位置显示
